## 一、产品定性：这是一个 Agent，不是一个表单

### 1.1 本质定义

**Seller Agent 是 ACCIO WORK 的一个 Plugin SubAgent。**

用户不填表单，不点按钮触发流程——用户**用自然语言说话**，Agent **理解意图、自主决策、输出结果**。

```
用户说: "我有一批 3kg 的手机壳要发去美国，帮我找最划算的渠道"
                              ↓
              Agent 自动解析出:
              - 货物: 手机壳（非带电、无液体）
              - 重量: 3kg
              - 目的地: 美国
              - 优先级: 成本优先（"最划算"）
                              ↓
              Agent 自动判断: 中小件 → 即时比价流程
                              ↓
              返回: 结构化比价结果卡片 + AI 推荐理由
```

### 1.2 对话驱动的能力边界

| 用户自然语言输入 | Agent 识别意图 | 触发能力 |
|---------------|--------------|---------|
| "帮我发一批货去德国，20公斤" | 中小件发货 - 成本/时效均衡 | 即时比价引擎 |
| "这票货要最快到，不计成本" | 中小件发货 - 时效优先 | 比价引擎（Time权重↑）|
| "我要出一个40尺柜去洛杉矶" | 大宗出口 - FCL | 大宗询价流程 |
| "这批电子产品怎么发，有锂电池" | 特货识别 → 合规检查 | 硬过滤 + 特货渠道 |
| "DHL 说我的货卡关了怎么办" | 异常处理 | 售后自愈建议 |
| "上次那票货发的什么渠道来着" | 历史查询 | 历史记录检索 |
| "帮我开一张面单" | 建单履约 | 面单生成 |

## 四、自然语言意图解析规范（Agent Brain）

### 4.1 货物类型自动判断逻辑

Agent 通过分析用户输入，**自动判断**货物类型，无需用户手动选择：

```
输入信号                      →  判断结果
"3公斤"  "几公斤"  "小包"       →  中小件
"一个柜"  "40HQ"  "整柜"       →  大宗（FCL）
"几吨"  "几百箱"  "LCL"        →  大宗（LCL）
"一托盘"  "木箱"               →  大宗（视重量定）
无法判断                        →  Agent 追问确认
```

### 4.2 意图识别关键词矩阵

```
发货类意图:
  ["发货", "运", "寄", "出口", "head程", "头程", "发去", "运到"]
  
询价类意图:
  ["多少钱", "报价", "价格", "怎么收费", "划算", "便宜", "最快"]
  
大宗类信号:
  ["整柜", "FCL", "LCL", "拼柜", "吨", "托盘", "整批"]
  
特货信号（触发硬过滤）:
  ["锂电", "带电", "电池", "液体", "粉末", "仿牌", "危险品"]
  
异常处理意图:
  ["卡关", "清关", "延误", "丢件", "投诉", "没动静", "怎么回事"]
  
建单意图:
  ["帮我建单", "开面单", "打单", "下单", "生成"]
```

### 4.3 追问策略

当信息不完整时，Agent **优先级追问**最关键缺失信息，而非一次要求所有信息：

```
缺失: 目的地        → "你的货发去哪个国家？"
缺失: 重量          → "大概多重？（几公斤 / 几吨）"
缺失: 货物描述      → "是什么商品？简单描述一下"
特货疑似           → "这批货有锂电池吗？"（确认特货标记）
重量临界(25-35kg)   → "这是一票单独的包裹，还是整批货物？"（确认分层）
```

## 五、5维评分模型规格（中小件专用）

```
Score = w₁×Cost + w₂×Time + w₃×Stability + w₄×Service + w₅×Risk

── 默认权重 ──────────────────────────────
  Cost      (成本，越低越好)  = 0.30
  Time      (时效，越快越好)  = 0.25
  Stability (历史准点率)      = 0.25
  Service   (客服/投诉率)     = 0.10
  Risk      (货损/丢件率)     = 0.10

── 动态调权规则（Agent 自动识别）──────────
  用户说"急"/"最快"/"今天要发"
      → Time +0.20，Cost -0.20
  
  用户说"便宜"/"最划算"/"预算有限"
      → Cost +0.15，Time -0.15
  
  系统识别为旺季（Q4: 10-12月）
      → Stability +0.10，Cost -0.10
  
  货值 > $500 / 单
      → Risk +0.15，Cost -0.15
  
  特货（带电/液体）
      → 进入硬过滤，排除无资质渠道（先于评分执行）

── Mock 渠道数据（供 Designer 参考）───────
  渠道名      Cost  Time  Stability  Service  Risk
  DHL Express  3.5   9.5    9.8       9.0     9.5
  云途小包     7.8   7.5    9.4       8.2     8.8
  4PX 标快     8.2   7.2    9.1       8.5     8.6
  燕文经济     9.5   5.5    8.8       7.5     8.0
  递四方小包   8.8   6.8    8.5       7.8     8.2
  （评分范围 0-10，越高越好）
```
